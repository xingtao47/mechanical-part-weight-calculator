# 机械零件重量计算器 V2.2

V2.2 支持直接修改清单里的零件，并保存完整计算参数。

## 新增功能

- 双击清单中的零件，或点击“修改选中项”进入编辑。
- 支持修改名称、数量、形状、单位、尺寸、材料和自定义密度。
- 点击“计算并更新”替换原记录，同时刷新单件重量、批次重量和总合计。
- 保存完整计算参数，重新打开清单后仍可编辑。
- 取消、切换、保存、导出或退出时处理尚未更新的修改。
- 左侧输入区支持纵向滚动，参数较多时仍能操作计算按钮。

## 操作方法

1. 双击清单中的一个零件，或选中后点击“修改选中项”。
2. 在左侧修改名称、数量、形状、尺寸、单位或材料。
3. 点击“计算并更新”，更新原行和汇总重量；点击“取消修改”可放弃。
4. 点击“保存清单”，下次打开 `.mpwc` 文件后仍能恢复完整参数。

## 旧清单兼容

支持打开 V2.1 清单。旧记录未保存原始尺寸，只能修改名称和数量，材料与单件重量保持原值。要修改其尺寸，请重新输入参数并添加新记录。

V2.2 保存的清单采用文件格式第 2 版，需要使用 V2.2 或更新版本打开。需要继续用旧软件查看时，请保留旧清单副本。

## 下载和运行

1. 在下方 Assets 区域下载 `Mechanical-Part-Weight-Calculator-V2.2-Windows.zip`。
2. 完整解压后双击 `机械零件重量计算器-V2.2.exe`。
3. ZIP 包含软件、中文使用说明和 MIT 许可证，无需安装 Python。

也可单独下载 `Mechanical-Part-Weight-Calculator-V2.2-Windows.exe` 运行。

面向 64 位 Windows 10 和 Windows 11。软件完全离线运行，内置材料密度采用常用近似值。
