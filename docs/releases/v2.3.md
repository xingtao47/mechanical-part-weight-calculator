# 机械零件重量计算器 V2.3

V2.3 新增三种零件的尺寸示意图，帮助识别输入框对应的尺寸位置。

当前状态：开发和本地自动测试已完成，等待界面验收；以下下载附件在正式发布后提供。

## 新增功能

- 实心圆柱：标出直径与长度。
- 空心圆柱：标出外径、内径与长度。
- 矩形块：标出长度、宽度与高度。
- 选择零件类型时，右侧图形与左侧输入字段同步切换。
- 编辑已有零件时显示保存的形状；旧记录没有形状和尺寸时显示说明。
- 示意图随窗口调整，最小窗口下仍可查看和滚动零件清单。

示意图用于识别尺寸位置，不按实际输入值比例绘制。

## 下载和运行

1. 下载下方 Assets 中的 `Mechanical-Part-Weight-Calculator-V2.3-Windows.zip`。
2. 完整解压，双击 `机械零件重量计算器-V2.3.exe`。
3. ZIP 包含软件、中文使用说明、验收步骤和 MIT 许可证，无需安装 Python。

也可单独下载 `Mechanical-Part-Weight-Calculator-V2.3-Windows.exe`。

面向 64 位 Windows 10 和 Windows 11，软件完全离线使用。

## 验收方法

1. 分别选择三种零件类型，核对图形和标注是否对应左侧输入字段。
2. 添加一个矩形块，双击修改，确认显示矩形块示意图；取消修改后确认返回默认圆柱图。
3. 打开 V2.2 清单并编辑记录，确认对应形状正常恢复。
4. 缩小窗口并再放大，确认图形、标注和零件清单可见。
