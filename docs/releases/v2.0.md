# 机械零件重量计算器 V2.0

V2.0 新增 Windows 桌面图形界面。下载 ZIP、解压并双击 EXE 即可使用，不需要安装 Python。

## 主要功能

- 支持实心圆柱、空心圆柱和矩形块。
- 支持毫米、厘米和米。
- 内置钢、铝、铜和钛，并支持自定义材料密度。
- 支持零件名称、数量、单件重量和批次重量。
- 支持连续添加多个零件并自动汇总。
- 支持删除记录、清空清单和导出 CSV。
- 输入错误时显示中文提示。
- 关闭未导出的清单时显示确认提示。
- 运行时不显示黑色终端窗口。

## 下载和运行

1. 在本 Release 的 Assets 区域下载 `机械零件重量计算器-V2.0.zip`。
2. 将 ZIP 完整解压到一个普通文件夹。
3. 双击 `机械零件重量计算器-V2.0.exe`。

本版本面向 64 位 Windows 10 和 Windows 11。EXE 没有进行商业代码签名；如果 Windows 显示安全提醒，请先确认文件来自本仓库的正式 Release。
