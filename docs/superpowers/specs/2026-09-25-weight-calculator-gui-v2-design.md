# 机械零件重量计算器 V2.0 图形界面设计

## 目标

将现有 V1.6 命令行程序升级为 Windows 桌面图形界面。用户双击 EXE 后直接看到操作窗口，不再出现黑色终端，同时保留现有计算、测试和命令行功能。

## 已确认范围

- 使用 Python 自带的 Tkinter/ttk 制作界面，不增加第三方 GUI 运行依赖。
- 使用单窗口左右分栏布局。
- 左侧负责输入，右侧负责显示本次结果、零件清单和汇总。
- 软件关闭后不自动保存清单；需要保留时由用户导出 CSV。
- 版本号升级为 V2.0。
- 保留现有命令行入口和全部计算逻辑。

## 主窗口布局

### 顶部

- 显示“机械零件重量计算器 V2.0”。
- 窗口使用适合普通笔记本屏幕的默认尺寸，并允许调整大小。

### 左侧输入区

- 零件名称。
- 数量，默认值为 1。
- 零件类型：实心圆柱、空心圆柱、矩形块。
- 尺寸单位：毫米、厘米、米。
- 根据零件类型动态显示尺寸输入框：
  - 实心圆柱：直径、长度。
  - 空心圆柱：外径、内径、长度。
  - 矩形块：长度、宽度、高度。
- 材料：钢、铝、铜、钛、自定义材料。
- 选择自定义材料时显示材料名称和密度输入框。
- “计算并添加”和“清空输入”按钮。

### 右侧结果区

- 显示最近一次计算的体积、单件重量和批次重量。
- 使用表格显示零件清单，包括零件名称、材料、数量、单件重量和总重量。
- 显示清单总数量和总重量。
- 提供“删除选中项”“清空清单”和“导出 CSV”按钮。

## 操作流程

1. 用户打开软件并填写左侧内容。
2. 点击“计算并添加”。
3. 程序先验证输入，再调用现有计算函数。
4. 计算成功后，将记录加入右侧表格并刷新汇总。
5. 用户可以继续添加其他零件、删除记录或清空清单。
6. 点击“导出 CSV”后，系统弹出“另存为”窗口，由用户选择位置和文件名。
7. 如果存在尚未导出的清单，关闭窗口前询问是否确定退出。

## 程序结构

- `weight_calculator.py`：继续保存版本号、材料表、体积公式、重量计算、记录创建、汇总和 CSV 写入等核心逻辑，并保留命令行入口。
- 新增 GUI 启动文件：负责 Tkinter 窗口、控件状态、输入转换、表格更新、保存对话框和消息弹窗。
- GUI 不重复编写重量公式，只调用 `weight_calculator.py` 中的函数，保证命令行版和图形版结果一致。
- 将输入验证设计为可独立测试的函数，减少对真实窗口操作的依赖。

## 输入检查与错误提示

- 零件名称不能为空。
- 数量必须是正整数。
- 所有尺寸和密度必须是大于 0 的数字。
- 空心圆柱内径必须小于外径。
- 自定义材料名称不能为空。
- 未选择清单记录时点击删除，应显示提示且不报错。
- 清单为空时点击导出，应提示先添加零件。
- CSV 保存失败或用户取消保存时，程序保持可用，不丢失当前清单。
- 错误内容使用中文弹窗说明，并保留已填写数据供用户修改。

## 数据与保存

- 当前零件清单只保存在程序运行期间的内存中。
- 正常关闭软件后不自动恢复上次清单。
- CSV 表头和合计行保持与 V1.6 兼容，使用 UTF-8 BOM，确保 Excel 可直接打开中文。
- 图形界面通过保存对话框接收完整目标路径，不再强制保存到项目的 `exports` 文件夹。
- 成功导出后记录“当前清单已导出”状态；清单发生增加、删除或清空后重新标记为未导出。

## 打包与兼容性

- 更新 `build_exe.ps1`，以 GUI 启动文件作为打包入口。
- PyInstaller 使用单文件和无控制台窗口模式，生成 `机械零件重量计算器-V2.0.exe`。
- Windows EXE 只面向 Windows；Python 源代码仍可在安装了 Python/Tkinter 的其他系统运行。
- 不修改、不添加或打包无关的 `pelican-cycling.html`。

## 测试与验收

- 现有 18 项核心逻辑测试继续通过。
- 增加 GUI 可独立测试的输入验证、记录更新和导出路径测试。
- 人工测试三种零件、三种尺寸单位、四种预设材料和自定义材料。
- 人工测试空值、文字、零、负数、非整数数量和无效内外径。
- 人工测试添加、删除、清空、汇总和 CSV 导出。
- 打包后确认双击 EXE 只打开图形窗口，不出现终端。
- 在另一台没有安装 Python 的 Windows 电脑上验证 EXE 启动、计算和导出功能。

## 不包含在 V2.0 中

- 不自动保存或恢复历史清单。
- 不连接数据库或网络服务。
- 不提供用户登录和在线同步。
- 不支持在同一个 EXE 中跨 Windows、macOS 和 Linux 运行。
