# 机械零件重量计算器 V1.0 设计说明

## 项目目标

制作一个适合 Python 初学者的命令行程序。用户输入实心圆柱零件的直径和长度，选择材料后，程序计算并显示零件重量。

## 功能范围

- 尺寸单位可选：毫米（mm）、厘米（cm）、米（m）。
- 一次计算中的直径和长度使用同一个单位。
- 材料可选：钢、铝、铜。
- 采用常用近似密度：钢 7.85 g/cm³、铝 2.70 g/cm³、铜 8.96 g/cm³。
- 计算结果同时显示千克（kg）和克（g）。
- 完成一次计算后，询问用户是否继续计算另一个零件。

## 程序流程

1. 显示程序名称。
2. 让用户选择尺寸单位。
3. 读取圆柱直径和长度。
4. 让用户选择材料。
5. 将尺寸换算为厘米。
6. 使用圆柱体积公式 `π × (直径 ÷ 2)² × 长度` 计算体积。
7. 使用 `重量 = 体积 × 密度` 计算克数，再换算为千克。
8. 显示结果并询问是否继续。

## 代码结构

程序保存在一个 `weight_calculator.py` 文件中，并拆分为职责清楚的小函数：

- 选择单位。
- 读取正数。
- 选择材料。
- 换算尺寸并计算重量。
- 控制程序的整体运行流程。

## 输入错误处理

- 输入文字或其他非数字内容时，解释需要输入数字并重新询问。
- 直径或长度小于等于零时，解释尺寸必须大于零并重新询问。
- 输入不存在的单位或材料选项时，显示有效选项并重新询问。

## 验证方法

- 分别使用 mm、cm、m 输入等价尺寸，确认结果一致。
- 分别选择钢、铝、铜，确认材料密度会改变结果。
- 尝试文字、无效选项、零和负数，确认程序不会崩溃并会要求重新输入。
- 使用手工计算结果核对程序输出。

## V1.0 不包含

- 图形界面。
- 空心圆柱或其他形状。
- 自定义材料和密度。
- 数据保存、安装包和网页版本。

这些内容可在完成并理解 V1.0 后再决定是否加入。
