# 机械零件重量计算器 V1.0

这是一个使用 Python 编写的命令行程序，用于计算实心圆柱零件的重量。

## 功能

- 支持毫米（mm）、厘米（cm）和米（m）
- 支持钢、铝和铜
- 自动计算圆柱体积和重量
- 自动处理无效选项、文字、零和负数
- 支持连续计算多个零件

## 计算公式

圆柱体积：

`体积 = π × (直径 ÷ 2)² × 长度`

零件重量：

`重量 = 体积 × 材料密度`

## 运行方法

在项目文件夹的终端中输入：

```powershell
python weight_calculator.py
```

然后按照程序提示输入单位、直径、长度和材料。

## 使用的材料密度

- 钢：7.85 g/cm³
- 铝：2.70 g/cm³
- 铜：8.96 g/cm³

以上密度为常用近似值，实际材料密度可能存在差异。
